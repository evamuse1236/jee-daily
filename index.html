Question 1

Physics, Current electricity JEE Main 2025 (April session)

A motor operating on $100\ \text{V}$ draws a current of $1\ \text{A}$. If the efficiency of the motor is $91.6\%$, then the loss of power in units of $\mathrm{cal/s}$ is

  1. A$4$
  2. B$8.4$
  3. C$2$
  4. D$6.2$
Show solutionHide solution

The power the motor does not turn into useful work is the power lost. We find it in watts, then change it to calories per second.

  1. The input power is voltage times current.

    $$P_{in} = VI = 100 \times 1 = 100\ \text{W}$$

  2. An efficiency of $91.6\%$ means $91.6\%$ of the input becomes useful output. The other $8.4\%$ is lost.

    $$P_{loss} = (100\% - 91.6\%) \times 100\ \text{W} = 0.084 \times 100 = 8.4\ \text{W}$$

  3. A watt is one joule per second, so the motor loses $8.4\ \text{J}$ every second. Use $1\ \text{cal} = 4.2\ \text{J}$ to convert to calories.

    $$P_{loss} = \frac{8.4}{4.2}\ \mathrm{cal/s} = 2\ \mathrm{cal/s}$$

  4. Option (B), $8.4$, is the loss in watts, not in cal/s. Option (C) gives the loss in cal/s.

Answer: (C) $2$

Question 2

Maths, Definite integration JEE Main 2024 (April session)

The integral

$$\int_0^{\pi/4} \frac{136 \sin x}{3 \sin x + 5 \cos x}\, dx$$

is equal to:

  1. A$3\pi - 50 \log_e 2 + 20 \log_e 5$
  2. B$3\pi - 25 \log_e 2 + 10 \log_e 5$
  3. C$3\pi - 10 \log_e (2\sqrt{2}) + 10 \log_e 5$
  4. D$3\pi - 30 \log_e 2 + 20 \log_e 5$
Show solutionHide solution

Write the top as a multiple of the bottom plus a multiple of the bottom's derivative. Each part then integrates easily.

  1. The denominator is $D = 3\sin x + 5\cos x$. Its derivative is $D' = 3\cos x - 5\sin x$. Write the numerator using $D$ and $D'$:

    $$\sin x = A(3\sin x + 5\cos x) + B(3\cos x - 5\sin x)$$

  2. Compare coefficients. For $\sin x$: $3A - 5B = 1$. For $\cos x$: $5A + 3B = 0$. Solving gives $A = \frac{3}{34}$ and $B = -\frac{5}{34}$.

  3. Split the integrand. Since $136 \cdot \frac{3}{34} = 12$ and $136 \cdot \frac{5}{34} = 20$:

    $$\frac{136\sin x}{D} = 12 - 20\,\frac{D'}{D}$$

  4. Integrate. We have $\int \frac{D'}{D}\,dx = \log_e D$, so the antiderivative is:

    $$12x - 20\log_e(3\sin x + 5\cos x)$$

  5. Put in the limits. At $x = \frac{\pi}{4}$: $D = \frac{3}{\sqrt2} + \frac{5}{\sqrt2} = \frac{8}{\sqrt2} = 4\sqrt2$. At $x = 0$: $D = 5$. So the integral equals:

    $$12\cdot\frac{\pi}{4} - 20\left[\log_e(4\sqrt2) - \log_e 5\right]$$

  6. Simplify. We have $4\sqrt2 = 2^{5/2}$, so $\log_e(4\sqrt2) = \frac{5}{2}\log_e 2$. The result is:

    $$3\pi - 50\log_e 2 + 20\log_e 5$$

Answer: (A) $3\pi - 50 \log_e 2 + 20 \log_e 5$
